# Week 2 Hands-on Exercises

## Day 1
Implement and test a Stack. Use gene symbols as sample data.

## Day 2
Implement and test a Queue. Model sequencing reads waiting for processing.

## Day 3
Implement a singly linked list. Store DNA sequence fragments as nodes.

## Day 4
Build an undirected gene-interaction graph. Add at least 10 genes and 20 edges.

## Day 5
Implement BFS and DFS. Compare the traversal order and explain when each is useful.

## Challenge
Create a `GeneNetwork` class using the graph implementation. Add:

- `add_gene(gene)`
- `add_interaction(gene_a, gene_b)`
- `neighbors(gene)`
- `shortest_hops(gene_a, gene_b)`

Do not use NetworkX for the core implementation.

## Deliverable
Write a short report explaining the time and space complexity of Stack, Queue, LinkedList, BFS, and DFS operations.
