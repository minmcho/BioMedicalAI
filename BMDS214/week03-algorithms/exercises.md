# Week 3 Hands-on Exercises

## Day 1 — Complexity

For each operation, determine the Big-O complexity:

- access an array element by index
- scan a list for a gene ID
- binary search a sorted list
- insert into an unsorted list
- merge sort

## Day 2 — Searching

Implement linear search and binary search without using `in`, `.index()`, or other search helpers.

Benchmark both algorithms for 100, 1,000, 10,000, and 100,000 sorted gene IDs.

## Day 3 — Elementary sorting

Implement insertion sort and selection sort. Count comparisons and swaps.

## Day 4 — Divide and conquer

Implement merge sort and quicksort. Draw the recursive calls for a list of eight elements.

## Day 5 — Biological application

Create 10,000 synthetic gene records. Sort by expression level and search for gene IDs.

Write 300–500 words explaining which algorithm you would choose for a large genomic database and why.

## Challenge

Implement a hybrid strategy: use binary search when data are sorted and hash-based lookup when exact identifiers are queried repeatedly. Explain the trade-offs in runtime and memory.
