# Biomedical Imaging Final Project — Classical Image Analysis Pipeline

## Brief
Build one end-to-end classical pipeline on a PUBLIC biomedical image dataset
(source + license documented): representation checks -> enhancement ->
segmentation -> features -> evaluation (Dice and/or AUC against a reference),
with a written interpretation. No real patient images, no diagnosis/treatment
claims — methods and evaluation only.

## Milestones
1. Proposal (1 page): dataset, question, pipeline sketch, evaluation plan
2. Milestone report: pipeline runs end to end; first Dice/AUC numbers with failure examples
3. Final report + demo: results, failure analysis, limitations, what a learned model (Biomedical Vision AI) would have to beat

## Deliverables in this folder
- proposal.md · milestone.md · final_report.md · pipeline code + tests · figures
